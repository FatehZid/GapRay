# Changelog

All notable changes to GapRay are listed here.

## [0.1.0] - 2026-11-21

First public release.

### Added

- Hover any element to see its outline and size.
- Click an element for one card: size, font, weight, line height, color, padding, radius.
- Drag over an area for a live x-ray: sizes, hatched padding, gaps, radius, and the colors used.
- Hold Alt (Option) and hover to measure the distance between two elements.
- Click any value to copy it, with a toast. Fails safely on plain http pages.
- The overlay stays correct on scroll and resize, on light and dark pages.
- Motion that respects reduced motion.
- Toolbar menu: Activate GapRay with its shortcut, Settings, version.
- Settings page: current shortcut with a Change button.
- Shortcut: Cmd/Ctrl+Shift+X. Esc exits.
- Permissions: activeTab and scripting only. No network calls.
